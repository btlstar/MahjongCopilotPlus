# 从 preview.1 升级

1. 关闭旧版程序及它启动的游戏浏览器，保留原目录作为备份。
2. 将 preview.2 完整解压到另一个可写目录；不要只替换 exe，配套模块也有更新。
3. 如需保留设置，把旧版根目录的 `settings.json` 复制到新版根目录。需要保留装扮时，再复制 `mjmax/config/settings.yaml`、`mjmax/config/settings.mod.yaml`（以实际存在的文件为准）。只复制自己的私人文件，不要使用发布示例覆盖旧文件。
4. 如需沿用登录状态及代理证书，可在程序全部关闭后复制旧版 `browser_data/`、`mitm_config/` 到新版。它们包含私人数据，仅保存在本机，不上传 GitHub。
5. 运行新版 `MahjongCopilotPlus.exe`。既有 OT 配置会继续使用旧版接口；到“设置 → AI 连接 → AkagiOT”手动选择“Akagi v3 · 可选模型”，填写该服务对应的密钥。
6. 默认四麻 `4p-akg-v8b-preview`、三麻 `3p-akg-v9`。获取可用模型、测试并保存配置后，在牌局中查看服务端实际模型回报。对局中更改会在当前对局结束后加载。

本地模型用户应保留自己的权重与模型路径；使用本地三麻或旧版 OT 三麻的用户还需保留原有兼容的三麻扩展。不要复制整个旧 `_internal/` 覆盖新版。Akagi v3 三麻无需该扩展。

公开 Windows zip 不包含私人配置；源码与便携目录中的个人设置也不会互相自动同步。回退时关闭新版，再从保留的旧目录启动。
