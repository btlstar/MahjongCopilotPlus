# MahjongCopilotPlus v0.1.0-preview.1

首个 Windows x64 便携预览版。基于 MahjongCopilot，参考 MahjongCopilot-max 并集成 MajsoulMax。当前支持雀魂，其他平台仍在规划中。

## 主要变化

- 深色 Qt 界面，对局／装扮／设置导航，程序内连接配置与诊断。
- 统一麻将牌样式，万／筒／索使用不同颜色，建议概率对齐。
- 只保留游戏内提示卡片，可拖动、保存位置，顶栏与设置开关即时同步。
- 两键老板键预设 `Alt+Q`、`Alt+Z`、`Alt+X`，支持自定义。
- AI 配置按来源切换，本地模型支持文件浏览选择。
- MajsoulMax 资源与协议适配、游戏窗口调整、手动模式缩放提示优化。
- HTTP 资源流式转发，减少缓冲等待；不保证改变 CDN／线路带宽。

## 下载与运行

下载 `MahjongCopilotPlus-0.1.0-preview.1-windows-x64.zip`，**完整解压**到可写目录，运行 `MahjongCopilotPlus.exe`。保留 `_internal` 和其他文件，不要只复制 exe。无需另装 Python，Chromium 已包含。

首次运行请配置自己的 AI 服务或兼容模型。不提供账号、API Key 或模型权重，自动打牌和自动加入默认关闭。

本包包含有对应源码的四麻引擎；**不包含三麻扩展和外部客户端注入组件**，相关功能需要另行安装，见仓库安装文档。
