# 一番街原生客户端（实验性）

当前接入 Windows 独立客户端：读取对局协议并转换为现有 AI 的 MJAI 事件，在 Copilot 主界面显示手牌与建议。三麻、四麻共用现有 AI 配置，Akagi v3 每次响应仍严格核验模型 ID，不切换备用模型。首次接入尚未经过真实账号对局验收。

本页的 RiichiCityUnlock 是可选外部代理工具；[RiichiCityStyle](https://github.com/btlstar/RiichiCityStyle) 是独立本地装扮插件，两者名称、程序和配置不同。仅使用 RiichiCityStyle 换装时，无需开启本页的外部代理开关。

## 启动与设置

1. 正常使用一番街 launcher 更新游戏，然后关闭 launcher 启动的游戏。Copilot 的入口应指向 **Game 目录内的 Mahjong-JP.exe**，不是 launcher。常规安装位置会自动识别；界面仍需保存配置。
2. 用 `start.bat` 启动 Copilot，在顶栏选择“一番街”，进入“设置 → 平台”。先结束其他平台的对局并关闭 Copilot 启动的游戏窗口，才能切换平台。
3. 选择捕获方式。推荐已准备好外部 proxinject 的用户选择“进程代理注入”，浏览选择完整工具目录中的 `proxinjector-cli.exe`，至少保留相邻的 `proxinjectee.dll` 及原包辅助文件；这些 exe／DLL 不随本仓库分发。没有该工具时可使用下述手动分流。
4. 可选启用 RiichiCityUnlock，选择完整工具目录中的 `RiichiCityUnlock.exe`。保留其 DLL、config 等所有配套文件，不能只移动 exe。解锁工具的个人配置与免费／捐赠模式保持原样；Copilot 不提供其内部装扮选择 UI。
5. 保存平台设置，等待连接更新。AI 连接沿用此前选择的来源和型号，首次使用仍需在“AI 连接”获取模型、选择并保存。
6. 点击“打开一番街”，从登录、进入房间到新小局完整捕获。建议显示在 Copilot 的“对局”页；底栏显示 AI 型号及 v3 核验结果。

自动捕获只对本次启动的游戏进程及其子进程生效，其他进程与系统代理不变。若先用 launcher 或双击 exe 打开游戏，再点击 Copilot，并不会接管已经运行的那个进程。请关闭后通过 Copilot 启动。

### 手动进程分流

在 Proxifier 等工具中为 `Mahjong-JP.exe` 建立规则，指向 `127.0.0.1:10999`，类型选择 HTTPS／HTTP CONNECT；端口以 Copilot 设置为准。`localhost`、`127.0.0.1`、`::1` 的本机连接应直连，其他应用保持原规则。先连接 Copilot，再启动客户端。工具的安装和系统证书确认不由本项目自动代办。

## 实际链路

```text
仅 AI：游戏 → 进程捕获 → Copilot HTTP 代理 → 游戏服务器
AI + 解锁：游戏 → 进程捕获 → Copilot HTTP 代理 → RiichiCityUnlock HTTP 41110 → 游戏服务器
AI 推理：Copilot → 已选择的 AI 服务（与游戏代理独立）
```

自动捕获在本机使用随机 SOCKS5 端口，再转为 Copilot 的 HTTP CONNECT；本机回环 IPC 直连，不把 Copilot 或解锁工具的入口再次套入代理。程序不改变 Windows 系统代理、路由或 TUN。

Copilot 默认本地端口为 10999，不能与解锁工具 41110 相同。未启用解锁时可单独配置一番街上游代理；留空表示应用层直连。启用解锁时，出站由外部工具负责，此处不再叠加原雀魂上游代理。TUN 仍可能接管游戏和 AI 的出站，规则排查见[网络说明](NETWORK.md)。

### 解锁工具证书

首次运行外部工具通常生成当前用户 `.mitmproxy/mitmproxy-ca-cert.pem`。Copilot 仅将其**公钥 CA 证书**和正常 Mozilla 根证书合并到本地专用信任文件，用于校验“Copilot → 解锁工具”的 TLS；不关闭上游 TLS 校验，不复制私钥，也不额外修改系统信任库。若工具使用其他证书目录，在平台设置中指定对应公共 PEM 文件。不要选择 `mitmproxy-ca.pem` 这类可能含私钥的文件。

游戏侧仍使用 Copilot 自有代理证书，沿用现有安装流程。具体游戏版本是否信任 Windows 证书存储仍需实际客户端验证；不要因连接失败而直接关闭所有 TLS 校验。

## 边界与排查

- 当前没有原生游戏内提示卡片、独立悬浮窗或自动打牌。选择一番街时，相应网页选项停用，自动操作页隐藏；不会执行雀魂鼠标操作。
- 中途重连恢复尚未实现。未捕获完整身份／座位表时不会猜测自己的座位；异常会停止该小局推理，完整的新小局可恢复。重新登录、重新进入房间可补齐身份信息。
- 不支持同时捕获多场对局；当前牌局期间不会把另一连接的事件混入 AI。
- 换平台、网络配置与进程捕获方式应在关闭原生客户端后应用；运行中保存网络设置会延后重启，避免主动切断当前客户端。正常退出游戏后再退出 Copilot；退出 Copilot 会停止本地代理与其启动的解锁工具，不会强制结束游戏本体。
- 解锁启动最多等待 30 秒。外部工具自身的版本检查、网络或配置错误会使启动失败；“诊断”中有 `riichicity-unlock.log` 和 `riichicity-capture.log` 入口。端口已被其他程序占用时不会擅自接管或结束对方。修复外部配置后可重新保存，或关闭解锁开关先验证 AI 链路。
- 诊断显示已识别协议帧数和最近命令名，便于区分“未捕获”“有协议但座位不完整”和“AI 请求失败”。不要公开完整私人日志、设置、登录资料和证书。
- 外部工具配置由它自己管理。当前对提供的历史发行包只做进程和 HTTP 代理组合，未解包、反编译或重新分发，也不保证适配未来所有游戏版本。

协议来源与许可见[来源记录](../game/riichicity/PROVENANCE.md)。本项目仅提供源码，通过 `start.bat` 启动。
